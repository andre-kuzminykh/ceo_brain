1. Process Goal

Produce the full reporting loop — morning / intraday / evening checklists, nothing-lost control, weekly fundraising status, executive summary, owner / process report and monthly review — by hand, pulling every signal / tracker / meeting source on each tick.

2. Process description
CEO Office

Step 1. Morning roll-up

Sweep comms channels + trackers + calendar; build morning checklist (open tasks, critical follow-ups, meetings, blockers, pending actions); write the morning executive summary.

CEO Office

Step 2. Intraday refresh

Re-check inbound and tracker changes during the day; refresh the checklist if priorities shift.

CEO Office

Step 3. Evening roll-up + nothing-lost check

End-of-day sync; build the evening checklist (overdue, no-owner, missing follow-up); run the nothing-lost check — unclosed signals, meetings without summary, stale statuses, missed follow-ups — and write the evening daily summary.

CEO Office

Step 4. Weekly fundraising status

Sync meetings, summaries, pipeline stages, intros, follow-ups, investor history, outreach and open tasks; compile the weekly fundraising status — meetings / summaries / open tasks / last touch / blockers / fund movement.

CEO Office

Step 5. Weekly executive + owner / process report

Write the weekly executive summary (overall picture / key changes / attention points) and the owner / process report — overdue follow-ups, no-owner tasks, meetings without summary, stalled funds, process quality issues.

CEO Office

Step 6. Monthly review

Collect period-level pipeline data, meetings, early-stage dynamics, active-fund changes, investor touches and execution data; analyse post-meeting dynamics and decline reasons; compile the monthly review draft.

3. Roles & responsibility
CEO Office

Single reporting loop — runs every daily / weekly / monthly roll-up and compiles reports by hand.

Daily Checklist (CHK)

Morning / evening task and follow-up store — built by hand each day.

Weekly / Monthly Report (RPT)

Compiled artifacts — populated manually per cadence tick.

4. Systems (Tools)

  • Email / LinkedIn / Telegram / Slack — daily signal sweep.
  • FST / NIN / FLW / LID — pipeline and investor source data.
  • Wishlists & outreach (WSH) — outreach context for weekly roll-up.
  • GCL / FRK — meeting calendars.
  • Daily Checklist (CHK) — morning / evening task list.
  • Weekly / Monthly Report (RPT) — report artifacts.

5. Artifacts

  • Morning checklist + exec summary — attention points for the day.
  • Evening checklist + daily summary — what is left / where is the risk.
  • Nothing-lost snapshot — unclosed signals, meetings without summary, stale statuses.
  • Weekly fundraising status — pipeline / last touch / blockers / movement.
  • Weekly exec summary + owner / process report.
  • Monthly review — funds, stages, decline reasons, post-meeting dynamics.

7. Pain points
1. Manual daily roll-ups

Morning and evening checklists and summaries are built by hand every day — overhead scales with pipeline volume.

2. Nothing-lost check by memory

Unclosed signals, meetings without summary and stale statuses are caught only if someone remembers to look.

3. Weekly fundraising status by hand

Friday reporting requires pulling meetings, summaries, stages, outreach and tasks from every source manually.

4. Owner / process issues surface late

Overdue follow-ups and no-owner tasks accumulate through the week and only appear at the weekly review.

5. Monthly review is heavy

Every monthly review reruns every source pull by hand — slow and inconsistent across months.
