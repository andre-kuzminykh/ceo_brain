1. Process Goal

Run the entire operational meeting loop by hand: coordinate slots, chase unconfirmed bookings, classify every meeting by type, route fundraising meetings into a separate contour, produce post-meeting tasks and track CEO calendar load.

2. Process description
CEO Office

Step 1. Monitor meeting signals + calendars

Sweep Email, LinkedIn, WhatsApp, Telegram and Slack for slot exchanges and meeting invites; monitor Google Calendar and the fundraising calendar for changes and pending bookings.

CEO Office

Step 2. Per signal: context, action type, owner

Pull prior thread from HubSpot, decide the action type (reply with slots / confirm / reminder / reschedule / add to calendar / log / brief prep / post-meeting follow-up), and set owner, due, priority and dependencies.

CEO Office

Step 3. Task creation + dedup

Create or update the meeting task in the orchestrator; check related open tasks and merge duplicates / recurring items by hand.

CEO Office

Step 4. Send slots / reminder / confirm

Send slots or replies via Email / LinkedIn (or coordinate manually via Telegram / WhatsApp). When the meeting is confirmed — create or update the calendar event and mark the task confirmed.

CEO Office

Step 5. Booking SLA — reminder or follow-up

If booking is pending and no reply — check gap and send a reminder via Email or a follow-up via LinkedIn / messenger, then update task status.

CEO Office

Step 6. Daily classification + analytics

Export meetings from the CEO calendar, classify them by type (investor / partner / internal / media) and update CEO calendar analytics manually.

CEO Office

Step 7. External fundraising routing + post-meeting

Copy external fundraising meetings into the fundraising calendar, check Fireflies for a transcript and spawn post-meeting tasks (summary / follow-up / next step / owner confirmation).

CEO Office

Step 8. Meeting-task ack + daily / weekly sync

Check ack, dependencies and reply-fact on every meeting task; aggregate the unified list daily and weekly, checking tails — pending bookings, missing reminders, no-owner tasks, duplicates, overdue follow-ups.

3. Roles & responsibility
CEO Office

Single orchestration loop — monitors signals, creates tasks, sends slots / reminders, classifies meetings, routes fundraising meetings and reconciles.

Suggested owners

CEO Office / Alina / Dima / Yohann — assigned manually per meeting task.

Calendars

GCL / FRK — passive stores updated only when CEO Office edits them.

4. Systems (Tools)

  • Email / LinkedIn / WhatsApp / Telegram / Slack — slot exchanges and meeting messaging.
  • HubSpot — prior thread and templates.
  • Google Calendar + Fundraising calendar — events and pending bookings.
  • CEO calendar analytics (CAL) — classification & time breakdown, updated by hand.
  • Fireflies — transcript source.
  • Task Orchestrator / Daily Checklist (CHK) — meeting tasks.

5. Artifacts

  • Meeting task — entity, action type, owner, due, dependency, source.
  • Calendar event — created / updated in GCL.
  • Fundraising meeting record — in FRK.
  • CEO calendar analytics — by meeting type and time.
  • Post-meeting task bundle — summary, follow-up, next step, owner confirmation.

7. Pain points
1. Manual slot coordination and reminders

Every slot exchange, confirmation and reminder is done by hand — booking loop is slow and easy to lose track of.

2. Meeting classification and routing by hand

Investor / partner / internal / media tagging and FRK routing depend on who is managing the calendar that day.

3. Prep materials assembled manually

Upcoming external-meeting briefs are built from scratch each time — prep slips when the week is dense.

4. Booking pending tails

Meetings with pending bookings silently pile up — no systematic SLA on booking confirmation.

5. CEO time analytics is not actionable

Analytics are updated by hand — no optimization signals for overload, conflicts or inefficient windows.

1. Process Goal (TO-BE)

Calendar is a single agent that runs the operational meeting loop: coordinates slots, chases unconfirmed bookings, classifies meetings by type, auto-routes fundraising meetings into FRK, prepares upcoming briefs and delivers CEO-time analytics with optimization recommendations.

2. Process description
Calendar

A. Auto signal monitoring and event detection

Monitors Email, LinkedIn, WhatsApp, Telegram, Slack and both calendars in parallel, then classifies every signal into a meeting event (new / slots / pending / confirmed / reminder / reschedule / post-meeting) with entity, channel and urgency.

Calendar → CHK

B. Per signal: action type, owner, dedup task

Chooses action type and owner (CEO Office / Alina / Dima / Yohann), creates or updates the meeting task, and merges duplicates / recurring items automatically.

Calendar

C. Send slots / confirmations

Sends slots, reminders and follow-ups via Email or LinkedIn; for Telegram / WhatsApp drafts the message for manual send. Updates calendar on confirmation and keeps task status in sync.

Calendar

D. Booking SLA — reminder or follow-up

On pending bookings without reply, checks gap and emits a reminder (Email) or a follow-up (LinkedIn / messenger). Records confirmed bookings.

Calendar → COO

E. Daily classification + analytics snapshot

Classifies meetings (investor / partner / internal / media), updates CEO calendar analytics and detects overload, conflicts and inefficient windows — delivered as a calendar analytics snapshot.

Calendar → FRK

F. Auto-routing fundraising externals

For every external meeting determines the type: fundraising / investor events are auto-added to the fundraising contour; others stay in the main calendar. Related prep / follow-up tasks are spawned in CHK.

Calendar → COO

G. Upcoming meetings pack

For upcoming external meetings collects comms history from HubSpot and fundraising context from FRK, builds a pre-meeting draft (who / why / history / open questions / next-step hypothesis) and delivers the pack with prep tasks.

Calendar

H. Post-meeting + ack control + daily / weekly sync

Builds post-meeting summary and tasks, runs ack / blocked / reply-fact control, and produces a daily-and-weekly calendar control pack with meeting tasks, booking risks, upcoming externals and CEO-time optimization recommendations.

3. Roles & responsibility (RACI)

Calendar

Module 05

Calendar — Meeting Orchestration & CEO Time Analytics

Coordinates slots, tracks unconfirmed bookings, classifies meetings, routes fundraising events, prepares upcoming briefs and delivers actionable CEO-time analytics.

Time optimization May 13, 2026 № 05

What this module does

Calendar runs the operational meeting loop: it coordinates slots, chases unconfirmed bookings, classifies meetings by type and routes fundraising meetings into a separate loop. It delivers the upcoming external-meeting list, prep drafts and analytics of how CEO time is spent — with optimisation recommendations.

User stories

  1. The agent helps negotiate slots, coordinates meetings and reminds on unconfirmed bookings — no manual back-and-forth.
  2. Meetings are auto-classified: investor, partner, internal, media — no manual calendar tagging.
  3. External fundraising meetings auto-route into a dedicated fundraising loop — no manual copy-across.
  4. Get a list of nearest external meetings with draft prep materials — briefing in advance.
  5. See CEO-calendar analytics by meeting type and time — to evaluate where management focus goes.

Delivery requirements

  • Multi-channel meeting signal monitoring: Email, LinkedIn, WhatsApp, Telegram, Slack, Google Calendar, fundraising calendar.
  • Meeting classifier: investor / partner / internal / media.
  • Booking SLA and reminder engine with channel-appropriate drafts.
  • Pre-meeting prep pipeline: history, theses, open questions, next-step hypothesis.
  • CEO-time analytics with overload / conflict / inefficient-window detection and optimization suggestions.
