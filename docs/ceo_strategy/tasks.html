1. Process Goal

Capture every task hidden inside emails, messages, meetings and summaries and drive each one to closure with a clear owner, due date, dependencies and ack. CEO Office runs the entire orchestration manually — collect signals, classify, assign, control execution, dedup and escalate.

2. Process description
CEO Office

Step 1. Collect signals across channels

Monitor Email, LinkedIn, WhatsApp, Telegram and Slack in parallel; sweep trackers (FST / NIN / FLW / LID / WSH) and calendars (GCL / FRK) for new activity, then aggregate into a draft task list.

CEO Office

Step 2. Classify and pull source context

Determine action type — reply / follow-up / reminder / intro / NDA / Data Room / edits / meeting prep. Pull thread context from HubSpot for emails, meeting history from FRK for meetings, or fetch the Fireflies transcript and run it through a GPT script for transcripts (manual summary if missing).

CEO Office

Step 3. Suggested owner, due, dependencies

Decide owner (CEO Office / Alina / Dima / Yohann), due date, priority and dependencies. Pull Data Room status only when document context is required.

CEO Office

Step 4. Create / update task with dedup check

Create or update the task in the orchestrator (title, entity, owner, due, status, dependencies, source). Manually check for duplicates / recurring and merge or link if needed.

CEO Office

Step 5. Ack / blocker / reply control

Check ack status per owner — mark pending ack and escalate if missing; mark blocked / waiting dependency when relevant; verify reply fact in HubSpot when external response is required.

CEO Office

Step 6. Daily roll-up + alarm escalation

Aggregate tasks across all sources; check overdue, no-owner, pending ack, missing follow-up, recurring tasks and gap > 10 days. Mark alarms and urgent follow-ups when critical tails appear.

CEO Office

Step 7. Weekly execution review

Sync fundraising meetings, follow-ups and the unified task list. Analyse execution by owner, action type and tail items, and surface systemic issues — duplicates, stalled follow-ups, no-owner tasks, missed dependencies.

3. Roles & responsibility
CEO Office

Single orchestration loop — collects, classifies, assigns, dedups, controls and escalates every task by hand.

Suggested owners

CEO Office / Alina / Dima / Yohann — assigned manually per task.

Source systems

Email, chats, trackers, calendars, Fireflies — passive sources that surface signals only when checked.

4. Systems (Tools)

  • Email / LinkedIn / WhatsApp / Telegram / Slack — channel signals.
  • HubSpot — thread, template and reply-fact context.
  • FST / NIN / FLW / LID / WSH — fund and outreach trackers.
  • GCL / FRK — meeting calendars.
  • Fireflies + GPT script — transcripts and summary generation.
  • Data Room — document context for NDA / access / edits.
  • Task Orchestrator / Daily Checklist (CHK) — task store, manually maintained.

5. Artifacts

  • Task records — title, entity, owner, due, status, dependencies, source.
  • Daily checklist — open tasks per owner / due / status.
  • Escalation flags — alarm / escalate / urgent follow-up.
  • Weekly task review — overdue, no owner, blocked, duplicates, gaps.
6. Metrics (Observed)
MetricObserved value

Escalation lagUntil the daily roll-up — overdue and pending ack accumulate before being noticed.
Reply-fact trackingManual HubSpot check per task that depends on an external response.
7. Pain points
1. Manual task extraction

Every email, message, meeting or summary has to be reviewed and turned into a task by hand — slow, easy to miss.

2. Owner assignment by memory

No rules engine — owner decisions depend on who is processing the signal and what they remember about the entity.

3. Duplicates slip through

Without automatic deduplication the same task can land in the orchestrator multiple times from different sources.

4. Late escalations

Overdue, pending ack and missing follow-up only surface at the daily roll-up — early signals of stalled execution are lost.

5. No-owner / stalled tasks accumulate

Tasks without an owner or with stalled execution stack up silently — they only appear in the weekly review when they're already late.

1. Process Goal (TO-BE)

Tasks is a single agent that extracts every task automatically from emails, messages, meetings and summaries, proposes owner / due / action type / dependencies, and controls ack, status, overdue, duplicates and missing owner in real time. CEO Office consumes suggested tasks, alerts and weekly reviews instead of running the orchestration by hand.

2. Process description
Tasks

A. Auto signal collection + classification

Monitors Email, LinkedIn, WhatsApp, Telegram, Slack, fund and outreach trackers and both calendars in parallel; aggregates into a draft task list and classifies every signal (reply / follow-up / reminder / intro / NDA / Data Room / edits / meeting prep).

Tasks

B. Source context and summary

For emails pulls HubSpot thread and template, for meetings pulls FRK history, for transcripts pulls Fireflies and generates summary + follow-up + suggested task (builds summary from notes + calendar if transcript is missing).

Tasks

C. Suggested owner, due, priority, dependencies

Auto-suggests owner (CEO Office / Alina / Dima / Yohann), due date, action type, priority and dependencies. Pulls Data Room context only when document action is implied.

Tasks → CHK

D. Create / update task with dedup

Creates or updates the task record (title / entity / owner / due / status / dependencies / source / action type). Automatic duplicate / recurring detection merges or normalises related open tasks.

Tasks → CEO Office

E. Suggested task pack

Sends a suggested task to CEO Office — what to do, owner, due, action type, dependencies, source — so decision-making is instant.

Tasks

F. Ack / status / execution control with alerts

Continuously checks ack, dependencies and reply-fact; emits alerts to CEO Office on missing ack / blocked / waiting dependency and keeps the task status in sync with HubSpot reply events.

Tasks

G. Daily roll-up + escalation pack

Checks overdue, no-owner, pending ack, missing follow-up, gap > 10 days and stalled execution. If critical tails exist — sends an escalation pack; otherwise confirms clean daily status.

CEO Office → Tasks

H. Weekly task review pack

On weekly trigger: syncs meetings, fund follow-ups and the unified task list; analyses execution by owner, action type and tails; returns a weekly task review covering owner load, overdue, blocked, duplicates, no-owner and execution gaps.

Module 03

Tasks — Automated Extraction & Execution Control

Auto-extracts tasks from emails, chats, meetings and summaries, assigns owner, due and action type, and drives every assignment to a result with real-time ack, dependency and escalation control.

Productivity May 6, 2026 № 03

What this module does

Tasks automatically extracts tasks from emails, messages, meetings and summaries; assigns owner, track and due date. It provides the single execution control loop: status, dependencies, reply fact, overdue, duplicates and no-owner items — so nothing is lost and every assignment is driven to a result.

User stories

  1. From an email, message, meeting or summary a task is created automatically with suggested owner, due date and action type — nothing is lost.
  2. The agent suggests the owner — CEO Office, Alina, Dima or Yohann — to distribute work faster.
  3. Get clear tasks for NDA, Data Room, revisions and follow-ups — you immediately know what to do.
  4. See per-task ack, due date, status, dependencies and reply fact — to control assignments across all owners.
  5. See the unified open-task list, per-owner tasks, recurring tasks, overdue and no-owner items — to escalate and close tails fast.

Delivery requirements

  • Signal-to-task extraction across Email, LinkedIn, WhatsApp, Telegram, Slack, HubSpot, FST / NIN / FLW / LID / WSH, GCL, FRK, Fireflies and Data Room.
  • Task schema: title, entity, suggested owner, due date, status, dependencies, source, action type.
  • Ack and escalation flow: no ack / pending ack / blocked / waiting dependency / reply received.
  • Duplicate detection and task merging.
  • Daily and weekly task review packs for CEO Office.
