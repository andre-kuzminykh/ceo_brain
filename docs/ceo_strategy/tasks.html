    COO->>COO: Determine action type [reply / follow-up / reminder / intro / NDA / Data Room / edits / meeting prep]

    alt Source = email / message / reply

1. Process Goal

Capture every task hidden inside emails, messages, meetings and summaries and drive each one to closure with a clear owner, due date, dependencies and ack. CEO Office runs the entire orchestration manually — collect signals, classify, assign, control execution, dedup and escalate.

2. Process description
CEO Office

Step 1. Collect signals across channels

Monitor Email, LinkedIn, WhatsApp, Telegram and Slack in parallel; sweep trackers (FST / NIN / FLW / LID / WSH) and calendars (GCL / FRK) for new activity, then aggregate into a draft task list.

CEO Office

Step 2. Classify and pull source context

Determine action type — reply / follow-up / reminder / intro / NDA / Data Room / edits / meeting prep. Pull thread context from HubSpot for emails, meeting history from FRK for meetings, or fetch the Fireflies transcript and run it through a GPT script for transcripts (manual summary if missing).

CEO Office

Step 3. Suggested owner, due, dependencies

Decide owner (CEO Office / Alina / Dima / Yohann), due date, priority and dependencies. Pull Data Room status only when document context is required.

CEO Office

Step 4. Create / update task with dedup check

Create or update the task in the orchestrator (title, entity, owner, due, status, dependencies, source). Manually check for duplicates / recurring and merge or link if needed.

CEO Office

Step 5. Ack / blocker / reply control

Check ack status per owner — mark pending ack and escalate if missing; mark blocked / waiting dependency when relevant; verify reply fact in HubSpot when external response is required.

CEO Office

Step 6. Daily roll-up + alarm escalation

Aggregate tasks across all sources; check overdue, no-owner, pending ack, missing follow-up, recurring tasks and gap > 10 days. Mark alarms and urgent follow-ups when critical tails appear.

CEO Office

Step 7. Weekly execution review

Sync fundraising meetings, follow-ups and the unified task list. Analyse execution by owner, action type and tail items, and surface systemic issues — duplicates, stalled follow-ups, no-owner tasks, missed dependencies.

3. Roles & responsibility
CEO Office

Single orchestration loop — collects, classifies, assigns, dedups, controls and escalates every task by hand.

Suggested owners

CEO Office / Alina / Dima / Yohann — assigned manually per task.

Source systems

Email, chats, trackers, calendars, Fireflies — passive sources that surface signals only when checked.

4. Systems (Tools)

  • Email / LinkedIn / WhatsApp / Telegram / Slack — channel signals.
  • HubSpot — thread, template and reply-fact context.
  • FST / NIN / FLW / LID / WSH — fund and outreach trackers.
  • GCL / FRK — meeting calendars.
  • Fireflies + GPT script — transcripts and summary generation.
  • Data Room — document context for NDA / access / edits.
  • Task Orchestrator / Daily Checklist (CHK) — task store, manually maintained.

5. Artifacts

  • Task records — title, entity, owner, due, status, dependencies, source.
  • Daily checklist — open tasks per owner / due / status.
  • Escalation flags — alarm / escalate / urgent follow-up.
  • Weekly task review — overdue, no owner, blocked, duplicates, gaps.

7. Pain points
1. Manual task extraction

Every email, message, meeting or summary has to be reviewed and turned into a task by hand — slow, easy to miss.

2. Owner assignment by memory

No rules engine — owner decisions depend on who is processing the signal and what they remember about the entity.

3. Duplicates slip through

Without automatic deduplication the same task can land in the orchestrator multiple times from different sources.

4. Late escalations

Overdue, pending ack and missing follow-up only surface at the daily roll-up — early signals of stalled execution are lost.

5. No-owner / stalled tasks accumulate

Tasks without an owner or with stalled execution stack up silently — they only appear in the weekly review when they're already late.
